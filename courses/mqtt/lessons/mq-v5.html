MQTT 5 (2019) is the current version, and Mosquitto, HiveMQ, EMQX and most new client libraries speak it. NATS speaks 3.1.1 only, and so does a lot of firmware. Know what 5 adds, so you know what you're giving up and what to do instead.

What MQTT 5 adds

FeatureWhat it solvesOn 3.1.1, instead
Reason codes on every ackWhy a subscribe or publish was refused, not just that it wasThe broker's log
Session expiry intervalSessions that clean themselves up after N seconds offlineA broker-side expiry setting
Message expiryA queued command that's too old to act on is droppedA timestamp in the payload, checked by the receiver
Shared subscriptions $share/group/topicSeveral workers share one stream of messages, each gets someOne subscriber, or NATS queue groups on the NATS side
Response topic, correlation dataRequest/response with a reply addressA reply_to and an id in the JSON payload (lesson 11)
User propertiesHeaders: key/value metadataFields in the payload
Content type, payload formatSays what the bytes areOne format per topic, documented
Topic aliasesA short number instead of a long topic, saving bytesShort topics
Will delayDon't announce "offline" for a reconnect that takes two secondsTolerate a brief offline in the dashboard

Clean start replaces clean session

In 5, "clean session" splits in two: clean start (throw away an existing session at connect) and the session expiry interval (how long to keep it after disconnect; 0 is "end with the connection"). clean_session=True in 3.1.1 is clean start plus expiry 0; False is no clean start plus "keep it".

Connecting a 5 client to a 3.1.1 broker

Clients pick the protocol version in CONNECT. A client set to 5 against NATS gets CONNACK code 1, "unacceptable protocol version", and some libraries just report "connection refused". Set the version explicitly: in paho, protocol=mqtt.MQTTv311; in aiomqtt, protocol=aiomqtt.ProtocolVersion.V311.

From NATS

Most of what MQTT 5 adds, core NATS and JetStream already have: headers, request/reply with inboxes, queue groups, per-message expiry in streams. So the household's split stays clean: devices speak 3.1.1 MQTT to the leaf, and your own programs that need the richer features speak NATS to the same server.

Trap

Copying an MQTT 5 example (with properties= or $share/) into a client for a 3.1.1 broker. Shared subscription filters are just odd topic filters there, and match nothing you publish.
