FastAPI decides where each parameter comes from by looking at its name and type. Learn the three rules and you can read any endpoint.

The rules

  1. Name appears in the path ({device_id}) → path parameter.
  2. Simple type (int, str, bool, float, enum, date) and not in the path → query parameter.
  3. Pydantic model → request body (JSON).
@app.put("/devices/{device_id}")
def update_device(
    device_id: int,            # path
    body: DeviceUpdate,        # body (JSON)
    dry_run: bool = False,     # query: ?dry_run=true
    q: str | None = None,      # optional query
):
    ...

A query param with no default is required; missing it is a 422.

Validation with Annotated

from typing import Annotated
from fastapi import Path, Query, Header, Cookie, Body

@app.get("/devices")
def list_devices(
    limit: Annotated[int, Query(ge=1, le=100)] = 20,
    offset: Annotated[int, Query(ge=0)] = 0,
    serial: Annotated[str | None, Query(max_length=64, pattern=r"^[A-Z0-9-]+$")] = None,
    tag: Annotated[list[str], Query()] = [],        # ?tag=a&tag=b
):
    ...

@app.get("/devices/{device_id}")
def get_device(device_id: Annotated[int, Path(gt=0)]): ...
Trap

tags: list[str] without Query() is read as a body, because a list isn't a "simple" type. Lists from the query string always need Query(). (The = [] default is safe here: FastAPI copies it per request; in your own functions it is the mutable-default trap.)

Headers and cookies

def endpoint(
    user_agent: Annotated[str | None, Header()] = None,        # User-Agent
    x_request_id: Annotated[str | None, Header()] = None,      # X-Request-Id
    session: Annotated[str | None, Cookie()] = None,
): ...

Underscores become hyphens for headers automatically.

Several bodies, single values in a body

Two model parameters make FastAPI expect {"device": {...}, "owner": {...}}. Body() pulls a plain value from the JSON instead of the query: priority: Annotated[int, Body()].

Forms and files

For HTML forms and uploads (needs python-multipart): Form() and UploadFile. JSON APIs rarely need them.

Enums for fixed choices

from enum import StrEnum
class Status(StrEnum):
    active = "active"
    revoked = "revoked"

@app.get("/certs")
def certs(status: Status = Status.active): ...   # anything else → 422
From PHP

Path params are Laravel route params, query params are $request->query(), the body model is a FormRequest's validated(), and the Query(ge=1, le=100) limits are validation rules, all in the signature.

For each parameter of def search(org_id: int, body: Filters, page: int = 1, tags: list[str] = Query([])) on route /orgs/{org_id}/search, say where it comes from. Then check your answer in /docs.
