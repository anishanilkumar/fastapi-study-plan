Classes work much like PHP's, with less ceremony: no visibility keywords, and self written out.

A class

class Account:
    fee = 0.5                        # class attribute, shared by all instances

    def __init__(self, owner: str, balance: float = 0.0):
        self.owner = owner           # instance attributes are created here
        self.balance = balance

    def deposit(self, amount: float) -> None:
        if amount <= 0:
            raise ValueError("amount must be positive")
        self.balance += amount

    def __repr__(self) -> str:      # what the REPL and logs show
        return f"Account({self.owner!r}, {self.balance})"

acc = Account("Asha")                # no "new"
acc.deposit(10)

self is $this, passed explicitly as the first parameter. __init__ is the constructor.

No private

Everything is public. A leading underscore (self._cache) is the convention for "internal, don't touch". Two underscores trigger name mangling; you rarely need it.

Properties

class Cert:
    def __init__(self, not_after):
        self.not_after = not_after

    @property
    def expired(self) -> bool:      # read like an attribute: cert.expired
        return self.not_after <= datetime.now(timezone.utc)

Inheritance

class SavingsAccount(Account):
    def __init__(self, owner, rate):
        super().__init__(owner)
        self.rate = rate

Dunder methods

Double-underscore methods hook into language features: __eq__ for ==, __len__ for len(), __iter__ for for, __enter__/__exit__ for with, __str__ for str().

dataclasses

For classes that mostly hold data, @dataclass writes __init__, __repr__ and __eq__ for you from type hints.

from dataclasses import dataclass, field

@dataclass
class Device:
    serial: str
    model: str
    tags: list[str] = field(default_factory=list)   # not tags=[]!
    active: bool = True

@dataclass(frozen=True)              # immutable, hashable
class Point:
    x: float
    y: float

Pydantic models (FastAPI lesson) look similar but also validate and convert input. Use dataclasses for internal data, Pydantic at the edges where untrusted data arrives.

Duck typing and Protocols

Python cares whether an object has the method, not what class it is. To describe "anything with a .send()" for the type checker, use typing.Protocol instead of an interface.

From PHP

public function __construct(private string $owner) (constructor promotion) is closest to a @dataclass. static methods exist (@staticmethod, @classmethod), and @classmethod is the idiomatic alternative constructor: Device.from_row(row).

Trap

A mutable class attribute (class Cache: items = {}) is shared by every instance, and in a server, by every request. Create per-instance state in __init__.
