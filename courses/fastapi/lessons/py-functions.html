Functions are where Python's argument handling shines, and where its most famous trap lives.

Defining and calling

def greet(name: str, greeting: str = "Hello") -> str:
    """One-line docstring: what it does."""
    return f"{greeting}, {name}"

greet("Asha")
greet("Asha", "Hi")
greet(greeting="Hi", name="Asha")    # keyword arguments, any order

Keyword-only and positional-only

def send(to, body, *, retries=3, timeout=10.0):
    ...
send("a@x.de", "hi", retries=1)      # retries must be named
send("a@x.de", "hi", 1)              # TypeError

Everything after a bare * must be passed by name. Use it for flags and options so call sites stay readable. (A / marks the ones before it positional-only; you'll see it in library signatures.)

*args and **kwargs

def log(msg, *args, **kwargs):
    print(msg, args, kwargs)

log("x", 1, 2, level="info")   # x (1, 2) {'level': 'info'}

*args collects extra positional arguments into a tuple, **kwargs extra keyword arguments into a dict. Common in wrappers and decorators that pass everything through.

The mutable default trap

Default values are evaluated once, when the def runs, not on each call. A mutable default is shared by every call.

def add_tag(tag, tags=[]):        # BUG
    tags.append(tag)
    return tags

add_tag("a")   # ['a']
add_tag("b")   # ['a', 'b']  ← same list as before

def add_tag(tag, tags=None):      # fix
    if tags is None:
        tags = []
    tags.append(tag)
    return tags

Same for def f(now=datetime.now()): the time is frozen at import. In a server that runs for weeks, that's a bug an interviewer will expect you to spot.

Scope and closures

A function can read variables from the enclosing scope (no use needed, unlike PHP closures). To assign to one, declare nonlocal (or global for module level, which is almost always a smell).

def counter():
    n = 0
    def inc():
        nonlocal n
        n += 1
        return n
    return inc

Decorators

A decorator is a function that takes a function and returns a replacement. @app.get("/") in FastAPI is a decorator: it registers your function as a route.

import functools, time

def timed(fn):
    @functools.wraps(fn)            # keep the name and docstring
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        try:
            return fn(*args, **kwargs)
        finally:
            print(fn.__name__, time.perf_counter() - start)
    return wrapper

@timed
def slow(): ...
From PHP

Named arguments work like PHP 8's. Python closures capture by reference automatically, so the PHP function() use (&$x) dance is just reading x (plus nonlocal to rebind it).
