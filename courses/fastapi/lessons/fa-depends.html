Depends() is FastAPI's dependency injection: a function whose result is passed into your handler. It's how you share the database session, the current user and permission checks without globals.

A simple dependency

from typing import Annotated
from fastapi import Depends

def pagination(limit: int = 20, offset: int = 0) -> dict:
    return {"limit": min(limit, 100), "offset": offset}

@app.get("/devices")
def list_devices(page: Annotated[dict, Depends(pagination)]):
    ...

FastAPI calls pagination per request, filling its parameters from the request too, and passes the result in.

With yield: setup and teardown

def get_db():
    with Session(engine) as session:
        yield session            # handler runs here
    # session closed after the response

DB = Annotated[Session, Depends(get_db)]   # reusable alias

@app.get("/devices/{device_id}")
def get_device(device_id: int, db: DB): ...

One fresh session per request, always closed. This is the pattern; a module-level session is the bug.

Chained dependencies: the current user

bearer = HTTPBearer()

def current_user(
    creds: Annotated[HTTPAuthorizationCredentials, Depends(bearer)],
    db: DB,
) -> User:
    user = lookup_token(db, creds.credentials)
    if user is None:
        raise HTTPException(401, "invalid token",
                            headers={"WWW-Authenticate": "Bearer"})
    return user

CurrentUser = Annotated[User, Depends(current_user)]

def require_admin(user: CurrentUser) -> User:
    if not user.is_admin:
        raise HTTPException(403, "admins only")
    return user

@app.delete("/devices/{device_id}", status_code=204)
def delete_device(device_id: int, db: DB, admin: Annotated[User, Depends(require_admin)]):
    ...

Within one request, a dependency used several times (get_db here, by both current_user and the handler) runs once and is shared.

Router-wide dependencies

router = APIRouter(prefix="/admin", dependencies=[Depends(require_admin)])

Every route on the router gets the check, so a new route can't forget it.

Overriding in tests

app.dependency_overrides[get_db] = lambda: test_session
app.dependency_overrides[current_user] = lambda: User(id=1, is_admin=False)

This is why things come through Depends rather than being imported: tests can swap them.

From PHP

Like Laravel/Symfony constructor injection and middleware rolled together, but per function. auth()->user() becomes a CurrentUser parameter; route middleware can:admin becomes dependencies=[Depends(require_admin)].

Trap

Forgetting the auth dependency on one endpoint is a common review finding. Prefer router-level dependencies, and scope queries by the user (where(Device.owner_id == user.id)), not just "is logged in".
