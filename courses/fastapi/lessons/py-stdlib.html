The standard library parts a web backend touches every day. Most interview bugs around time and secrets live here.

datetime: always aware

A naive datetime has no timezone; an aware one does. Mixing them raises TypeError, and a naive "now" on a server is whatever local zone its clock uses, often hours away from UTC.

from datetime import datetime, timedelta, timezone
from zoneinfo import ZoneInfo

now = datetime.now(timezone.utc)             # aware, UTC: use this
datetime.now()                               # naive local time: avoid
datetime.utcnow()                            # naive, deprecated: avoid

expires = now + timedelta(days=30)
local = now.astimezone(ZoneInfo("Europe/Paris"))    # for display only
now.isoformat()                              # '2026-11-07T10:00:00+00:00'
datetime.fromisoformat("2026-01-13T13:00:00+00:00")
def is_expired(not_after: datetime, now: datetime | None = None) -> bool:
    now = now or datetime.now(timezone.utc)
    if not_after.tzinfo is None:
        raise ValueError("not_after must be timezone-aware")
    return not_after <= now

Store and compare in UTC; convert to a zone only to show it. Passing now in makes the function testable.

secrets and hmac

import secrets, hmac, hashlib

token = secrets.token_urlsafe(32)            # unguessable token (not random.random!)
hmac.compare_digest(provided, expected)      # constant-time comparison
sig = hmac.new(key, body, hashlib.sha256).hexdigest()

Use secrets for anything security-related; random is predictable. Compare secrets with compare_digest, not ==, which can stop at the first differing byte and leak timing. Passwords need a slow hash (argon2, bcrypt) from a library, never sha256.

Trap

Building a path from user input (UPLOADS / filename) allows ../../etc/passwd. Resolve and check: p = (UPLOADS / name).resolve(); p.is_relative_to(UPLOADS.resolve()).

logging

import logging
log = logging.getLogger(__name__)       # one per module

log.info("device %s registered", serial)    # lazy formatting, not f-string
try:
    ...
except UpstreamError:
    log.exception("vendor call failed")     # logs the traceback too

Never log secrets, tokens or full request bodies. print is for scripts; servers use logging.

From PHP

hash_equals → hmac.compare_digest. random_bytes/bin2hex → secrets.token_hex. password_hash → a library (pwdlib/argon2, bcrypt). new DateTimeImmutable('now', new DateTimeZone('UTC')) → datetime.now(timezone.utc); Python datetimes are already immutable.
