PHP has one array that is both a list and a map. Python splits it into separate types, each better at its job.

list: ordered, by position

nums = [3, 1, 2]
nums.append(4)          # $nums[] = 4
nums.extend([5, 6])     # array_push(...)
nums.insert(0, 9)
nums.pop()              # remove and return the last
nums.remove(9)          # remove the first 9 (ValueError if absent)
len(nums)
nums[0], nums[-1]       # first, last
nums.sort()             # in place, returns None
sorted(nums)            # new sorted list

Slicing

seq[start:stop:step], with stop excluded. Works on lists, strings and tuples, and always returns a new object.

xs = [0, 1, 2, 3, 4, 5]
xs[1:4]     # [1, 2, 3]
xs[:2]      # [0, 1]
xs[-2:]     # [4, 5]
xs[::-1]    # reversed copy
xs[:]       # shallow copy

tuple: fixed, immutable

point = (3, 4). Used for small fixed groups and for returning several values: return total, count then total, count = f(). A one-item tuple needs a comma: (5,).

dict: by key

user = {"name": "Asha", "age": 31}
user["email"] = "a@x.de"
user["name"]                 # KeyError if missing
user.get("phone")            # None if missing
user.get("phone", "n/a")     # default
"age" in user                # isset-ish (but True even if the value is None)
del user["age"]
for key, value in user.items():
    print(key, value)
merged = {**defaults, **overrides}    # array_merge; also defaults | overrides

Dicts keep insertion order. Keys must be hashable (strings, numbers, tuples), so not lists.

set: unique, unordered

tags = {"python", "api"}
tags.add("web")
"api" in tags                # fast membership test
{1, 2, 3} & {2, 3, 4}        # {2, 3}  intersection
{1, 2} | {3}                 # union
set(["a", "a", "b"])         # deduplicate

Careful: {} is an empty dict; an empty set is set().

Mutability and references

Assigning a list or dict does not copy it. Both names point at the same object.

a = [1, 2]
b = a
b.append(3)
a          # [1, 2, 3]  ← changed too
c = a.copy()   # or list(a), a[:]; copy.deepcopy for nested data
From PHP

PHP arrays are copied on assignment (copy-on-write); Python lists and dicts are shared. Passing a list to a function and having it changed there is a classic surprise. Also, there's no auto-vivification: d["a"]["b"] = 1 fails if d["a"] doesn't exist. Use d.setdefault("a", {}) or collections.defaultdict(dict).
