Testing endpoints end to end, with the database and auth swapped for test versions, and upstream APIs faked.

TestClient

from fastapi.testclient import TestClient
from app.main import app

def test_create_device():
    with TestClient(app) as client:          # "with" also runs lifespan
        r = client.post("/devices", json={"serial": "A-1", "model": "X"})
        assert r.status_code == 201
        assert r.json()["serial"] == "A-1"

Calls go straight into the app in-process; no server needed. Write plain (sync) tests even for async def endpoints.

Overriding dependencies

# conftest.py
@pytest.fixture
def session():
    engine = create_engine("sqlite://", connect_args={"check_same_thread": False},
                           poolclass=StaticPool)
    Base.metadata.create_all(engine)
    with Session(engine) as s:
        yield s

@pytest.fixture
def client(session):
    app.dependency_overrides[get_db] = lambda: session
    app.dependency_overrides[current_user] = lambda: User(id=1, is_admin=False)
    with TestClient(app) as c:
        yield c
    app.dependency_overrides.clear()          # don't leak into other tests

The 409 test

def test_duplicate_serial_returns_409(client):
    body = {"serial": "A-1", "model": "X"}
    assert client.post("/devices", json=body).status_code == 201
    r = client.post("/devices", json=body)
    assert r.status_code == 409
    assert len(client.get("/devices").json()) == 1   # still exactly one

What it can't prove: that two concurrent requests are handled right. Sequential calls never hit the race; only the unique constraint does that. Saying so is the kind of judgement interviewers look for.

Faking upstream APIs

def handler(request: httpx.Request) -> httpx.Response:
    if request.url.path == "/certs/A-1":
        return httpx.Response(200, json={"status": "valid"})
    return httpx.Response(404)

transport = httpx.MockTransport(handler)
fake = httpx.AsyncClient(transport=transport, base_url="https://vendor.test")
app.dependency_overrides[get_http] = lambda: fake

Faking at the transport tests your real client code (URLs, headers, error handling), not a mock of it. Also test the failure paths: httpx.Response(500), or raise httpx.ConnectTimeout in the handler and assert you return 502/504.

Determinism

  • Time: pass now in, or override a get_now dependency. Never assert against the real clock.
  • Timezone: use aware UTC datetimes so the machine's TZ doesn't matter.
  • Network: none. MockTransport, overrides.
  • Order: each test builds its own data; clear overrides.
  • Randomness: inject or seed it.

What a test can't prove

Constant-time comparison, absence of races, behaviour under real load, that the real vendor still behaves like your fake. Name the limits; propose the complement (a constraint, a load test, a contract test).

From PHP

Laravel's $this->postJson() → client.post(json=...). Http::fake() → httpx.MockTransport. Container bindings in tests → dependency_overrides. Carbon::setTestNow() → inject now.
