Python's syntax is small. Most of what feels strange coming from PHP is just three things: indentation instead of braces, no sigils, and for always iterating over something.

Indentation is the block

if temperature > 30:
    print("hot")
    fan_on = True
elif temperature < 5:
    print("cold")
else:
    print("fine")
print("always runs")       # back at the left: outside the if

A colon opens a block; the indented lines are the block. Use 4 spaces, never tabs. There are no semicolons and no $ on variables. Comments start with #.

Variables

Assigning creates the variable. There is no declaration and no let/var. A name can be rebound to a value of a different type, but don't.

count = 0
name, age = "Asha", 31      # assign two at once (tuple unpacking)
a, b = b, a                 # swap without a temp

Loops

for walks over any iterable: a list, a string, a dict, a file, a range. There is no C-style for (i = 0; ...).

for fruit in ["apple", "fig"]:
    print(fruit)

for i in range(3):          # 0, 1, 2
    print(i)

for i in range(10, 0, -2):  # 10, 8, 6, 4, 2
    print(i)

while queue:
    job = queue.pop()
    if job is None:
        continue            # next iteration
    if job == "stop":
        break               # leave the loop
    run(job)

for ... else exists: the else runs if the loop finished without break. It's handy for searches, but readers often misread it, so use it sparingly.

Operators that differ

  • and, or, not instead of &&, ||, !.
  • / always gives a float (7 / 2 == 3.5); // is floor division; ** is power.
  • == compares values with no type juggling: "1" == 1 is False. There is no ===.
  • Chained comparisons work: 0 < x <= 10.
  • in tests membership: "a" in "cat", 3 in [1, 2, 3], "key" in some_dict.
  • Conditional expression: label = "even" if n % 2 == 0 else "odd" (PHP's ternary, reordered).

match (3.10+)

Like match in PHP 8, but it can also destructure:

match command.split():
    case ["go", direction]:
        move(direction)
    case ["quit" | "exit"]:
        stop()
    case _:
        print("unknown")
From PHP

elseif is elif. foreach ($items as $k => $v) is for k, v in items.items():. null, true, false are None, True, False, capitalised.

Trap

Mixing tabs and spaces, or an accidental extra indent, gives IndentationError, or worse, silently moves a line into or out of a block. Let your editor insert 4 spaces.
