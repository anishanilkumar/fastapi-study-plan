pytest is the standard test runner. Tests are plain functions with plain assert; fixtures provide what they need.

A test

# test_certs.py   (files and functions start with test_)
from certs import is_expired

def test_expired_cert():
    now = datetime(2026, 11, 10, tzinfo=timezone.utc)
    assert is_expired(datetime(2026, 11, 9, tzinfo=timezone.utc), now)

def test_naive_rejected():
    with pytest.raises(ValueError, match="aware"):
        is_expired(datetime(2026, 11, 9), now=datetime.now(timezone.utc))
pytest -q               # run all
pytest -k expired -x    # by name, stop at first failure
pytest -vv              # verbose, full diffs

When an assert fails, pytest shows both sides of the comparison. No assertEquals needed.

parametrize

@pytest.mark.parametrize("value, expected", [
    ("", False),
    ("0", True),
    (None, False),
])
def test_truthy(value, expected):
    assert bool(value) is expected

Fixtures

@pytest.fixture
def owner(db):                    # fixtures can use other fixtures
    o = Owner(name="Asha")
    db.add(o); db.commit()
    return o

@pytest.fixture
def db():
    engine = create_engine("sqlite://")       # in-memory
    Base.metadata.create_all(engine)
    with Session(engine) as session:
        yield session                         # teardown after yield

def test_add_device(db, owner):
    db.add(Device(serial="A-1", owner_id=owner.id)); db.commit()
    assert db.scalar(select(func.count()).select_from(Device)) == 1

A test asks for a fixture by naming it as a parameter. Put shared fixtures in conftest.py; pytest finds them automatically. scope="session" makes one shared instance for the whole run.

Built-in fixtures

  • tmp_path: a fresh temporary directory (a Path).
  • monkeypatch: set env vars or attributes for one test, undone after: monkeypatch.setenv("API_KEY", "x"), monkeypatch.setattr(module, "now", lambda: FIXED).
  • caplog, capsys: capture log records and printed output.

Good tests

  • One behaviour per test, named for it: test_duplicate_serial_returns_409.
  • Arrange, act, assert.
  • Test the edges: empty, None, boundary values, the error path.
  • No dependence on the clock, timezone, network, random order or other tests.
From PHP

PHPUnit → pytest. setUp() → fixtures. Data providers → parametrize. expectException → with pytest.raises(...). Mocks: monkeypatch or unittest.mock.
