SQLAlchemy 2.0 is the standard database toolkit. The ORM maps classes to tables; queries are built with select() and always use bound parameters.

Engine and models

from sqlalchemy import create_engine, ForeignKey, String, UniqueConstraint
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship

engine = create_engine("postgresql+psycopg://app:pw@localhost/app")   # once per process

class Base(DeclarativeBase):
    pass

class Owner(Base):
    __tablename__ = "owners"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(100))
    devices: Mapped[list["Device"]] = relationship(back_populates="owner")

class Device(Base):
    __tablename__ = "devices"
    id: Mapped[int] = mapped_column(primary_key=True)
    serial: Mapped[str] = mapped_column(String(64), unique=True)
    owner_id: Mapped[int] = mapped_column(ForeignKey("owners.id"))
    note: Mapped[str | None]                       # nullable because of | None
    owner: Mapped[Owner] = relationship(back_populates="devices")

The engine holds a connection pool and is safe to share. The Mapped[...] hints define column types and nullability.

Querying

from sqlalchemy import select
from sqlalchemy.orm import Session

with Session(engine) as session:
    d = session.get(Device, 5)                                  # by primary key, or None
    d = session.scalar(select(Device).where(Device.serial == serial))   # one or None
    ds = session.scalars(
        select(Device)
        .where(Device.owner_id == owner_id)
        .order_by(Device.id)
        .limit(20).offset(40)
    ).all()
    n = session.scalar(select(func.count()).select_from(Device))

Bound parameters, always

# BUG: SQL injection
session.execute(text(f"SELECT * FROM devices WHERE serial = '{serial}'"))

# fine: ORM expression (parameters are bound)
select(Device).where(Device.serial == serial)

# fine: raw SQL with a named parameter
session.execute(text("SELECT * FROM devices WHERE serial = :serial"), {"serial": serial})

Column and table names can't be parameters. If a client picks the sort column, map it through an allow-list: {"serial": Device.serial, "id": Device.id}[sort].

Async

For async def handlers: create_async_engine("postgresql+asyncpg://..."), AsyncSession, and await session.scalars(...). Lazy loading doesn't work in async; load relationships explicitly.

From PHP

Doctrine is the close match: entities ↔ mapped classes, EntityManager ↔ Session (unit of work, flush ↔ commit), QueryBuilder ↔ select(). Eloquent's active record ($device->save()) has no direct equivalent; changes go through the session.
