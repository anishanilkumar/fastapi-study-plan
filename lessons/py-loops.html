Python code reads best when it iterates directly over things instead of counting indexes. These tools replace most of PHP's array_* functions.

enumerate and zip

for i, name in enumerate(names, start=1):   # index and value
    print(i, name)

for name, score in zip(names, scores):      # walk two lists together
    print(name, score)

dict(zip(keys, values))                     # array_combine

Unpacking

first, *rest = [1, 2, 3, 4]       # 1, [2, 3, 4]
for user_id, (lat, lon) in positions.items():
    ...
def area(w, h): return w * h
area(*[3, 4])                     # spread a list into arguments
render(**{"title": "Hi"})         # spread a dict into keyword arguments

Comprehensions

A comprehension builds a list, dict or set from a loop in one expression. It replaces array_map plus array_filter.

squares = [n * n for n in range(10)]
active  = [u.name for u in users if u.active]
by_id   = {u.id: u for u in users}             # dict comprehension
domains = {e.split("@")[1] for e in emails}    # set comprehension
pairs   = [(x, y) for x in range(3) for y in range(3) if x != y]

Read it left to right as English: "u.name, for each u in users, if u is active". If it needs more than one if or nesting, write a normal loop instead.

Useful built-ins

sum(o.total for o in orders)          # generator expression, no [] needed
any(u.is_admin for u in users)
all(r.ok for r in results)
max(users, key=lambda u: u.age)
sorted(users, key=lambda u: (u.last, u.first))
sorted(scores.items(), key=lambda kv: kv[1], reverse=True)
min([], default=None)                 # min/max of empty raise without default

key= takes a function that returns what to sort by; it replaces usort with a comparator.

Trap

Don't add or remove items from a list or dict while looping over it. For a dict this raises RuntimeError: dictionary changed size during iteration; for a list it silently skips items. Build a new collection instead: items = [i for i in items if keep(i)].

From PHP

array_map(fn($u) => $u->name, array_filter($users, fn($u) => $u->active)) becomes [u.name for u in users if u.active]. in_array is in. array_keys/array_values are d.keys()/d.values(). count is len.
